# /honest-resume：生成诚实版简历

把审计后的可守住表述排进一份干净的可编辑 HTML，不追求「大厂极简同款」视觉 denseness，而追求面试官追问时仍站得住。

## 与 /resume、/asu-resume 的关系

| ASu | Defense-Asu `/honest-resume` |
| --- | ------------------------- |
| `/resume` 选模板做漂亮交付 | 固定诚实版版式，先内容后样式 |
| `/asu-resume` 同款高密度技术简历 | 主动降低密度与强动词，保留证据链接 |

## 资源定位

优先使用仓库插件布局 `../../assets/claim-audit-report.html` 旁的诚实版起点；若存在 `honest-resume-template.html` 则复制为用户专属文件，不修改母版。

若模板缺失，启用后备方案：生成单栏 A4 可编辑 HTML，包含打印隐藏工具栏与基础排版，并在交付说明中写明「使用后备模板」。

## 工作流程

1. 若尚无反酥化结论，先轻量执行 `/deasu` 或 `/resume-audit` 的核心步骤，再排版。
2. 只写入可守住内容；黄/红主张降级或移入「待补证据」区，不静默美化。
3. 开源与项目条目尽量附可点击链接（PR、仓库、文档、Demo）；无链接则标注 `待补链接`。
4. 输出用户专属 HTML 路径；需要 PDF 时说明浏览器打印为 A4。
5. 用户只要审计不要文件时，停留在 `/resume-audit`；只要追问时转入 `/probe`。

## 内容规则

- 职位、公司、时间、学历保持用户确认的真实信息。
- 禁用无证据的「主导 / Owner / 100% / 行业领先」。
- 数字必须带口径，例如「接口 P99 延迟（压测环境，N=…）」；无口径则改定性描述或删除。
- 技能栏只保留经历中出现过的技术；其余放入「了解」或删除。
- 自我评价不超过 3 句，且每句能被经历条目支撑。

## 默认交付

1. 诚实版可编辑 HTML 文件；
2. 相对原简历的删改摘要；
3. 仍标记为待补的证据列表。
